# AIネイティブチャットシステム「Kogack」

新人社員向けAI開発研修の成果物。社内チャットにAIエージェントが常駐し、質問への回答・依頼への対応・社内システムの操作までを行う社内Webシステムの設計ドキュメント一式と実装。

**[docs/index.html](docs/index.html) をブラウザで開くと全設計ドキュメントにアクセスできます。**

## 開発環境の起動方法

前提: Python 3.12+ / Node.js 22+ / PostgreSQL（**Docker とローカルインストールのどちらでもよい**）

**かんたん起動**: リポジトリルートの `start.bat` をダブルクリック（または実行）するだけで、DB・バックエンド・フロントエンドが順に起動する。設定はルートの `.env` で変更できる（初回実行時に `.env.example` から自動生成）。

初回のみ、事前に依存のインストールが必要:

```powershell
cd backend && python -m venv .venv && .venv\Scripts\pip install -r requirements.txt
cd frontend && npm install
```

DB は `.env` の `DB_MODE` で Docker / ローカルインストールを切り替える（既定 `auto` = ローカルにPostgreSQLサービスがあればそれを使い、無ければDockerを使う）。両方を同時には使えない。

Vite が表示するURL（既定 http://localhost:5174 、使用中なら5175等）を開き、ログイン画面の「開発用ログイン」からアカウントを選択する。Google OAuth・Supabaseは未接続でも動く（ローカル開発ではダミー認証で代替。姉妹プロジェクトKeirekiと同じ規約）。

現時点の実装範囲は認証（S-01）、チャンネル会話（S-02サイドバー・S-03、投稿・閲覧のみ）、DM（S-02サイドバー・補足02・DM会話画面）、スレッド表示（S-04）、横断検索（S-05、メッセージ検索のみ）、チャンネル設定（S-06、チャンネル管理者タブのみ）、管理コンソール（S-08、利用者管理タブのみ）まで（画面単位の縦切りで開発中。詳細は `CLAUDE.md` の「実装状況」を参照）。

## システム概要（将来像）

- AIはチャンネルごとに振る舞い（キャラクタ・参照ドキュメント範囲・スキル・反応の仕方・自動対応範囲）を定義し、そのチャンネルの担当部署が自ら調整する（第1層）
- 社内ドキュメント（Googleドライブ）への質問に、質問者本人の閲覧権限を尊重して回答する（第2層）
- 座席予約・e-learningなど社内システムの参照・登録・変更をチャットから行う。登録・変更は実行前に確認する（第3層）
- Google認証（許可ドメイン: kogasoftware.com）、既存Slackとの併存を前提
- 技術構成は既存システム（LCC CRM）を踏襲: React 19 + TypeScript / FastAPI / PostgreSQL (Supabase)

### 2026年9月末リリース（初期リリース）

第0層（チャンネル・スレッド・DM・検索・ファイル共有）と第1層（AIのキャラクタ・スキル・振る舞い・反応設定・履歴参照・要約・引き継ぎ）はほぼ全て実装する。第2層（ドキュメントQ&A・閲覧権限フィルタリング）も核として実装し、第3層は座席予約システムの参照のみを追加する（座席予約システム側が9月末までに参照可能な手段を用意できるかという外部依存リスクが残る）。社内システムへの登録・変更操作と、スマートフォン対応は対象外とする。対象外の一覧は [要件定義書3.2節](docs/02_要件定義書.html#sec3) を参照。自分たちだけでは決めきれない2件（コスト上限到達時の挙動、先行運用の対象部署）は [要件定義書8.2節「前提条件」](docs/02_要件定義書.html#sec8) に「千田氏との別途協議」として明記している。判定の経緯は `検討資料/` にまとめている。
