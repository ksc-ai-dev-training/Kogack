このチャンネルの管理者（chadmin）を設定します。チャンネル管理者はAI設定（この画面）の編集と、対応できない依頼の引き継ぎ先になります。

対象チャンネル: # 開発相談（公開チャンネル・12名参加）
このチャンネルを非公開にする
オンにすると、参加者以外には一覧・検索に表示されなくなります。参加には既存の参加者による追加が必要になります（F-34）。今は「公開」のためオフ。
複数人指定できます。最後の1人は解除できません（管理者不在の防止）。
田 田中 智子 chadmin
追加できるのはこのチャンネルの参加者のみです。システム管理者は全チャンネルのAI設定を編集できるため、ここへの追加は不要です。

会話ログ・スレッド・送信予約・AI設定を含め、このチャンネルのすべてのデータが完全に削除されます。この操作は取り消せません。削除するには、チャンネル名「開発相談」を下に入力してください。

日時・頻度を指定して、このチャンネルに自動でメッセージを投稿します（F-36）。チャンネルAIとは別物で、質問に答えたりはしません。通常のメッセージと区別できるよう、投稿ごとに送り主の名前・アイコンを設定します。

📢 お知らせBot BOT 毎週 月曜 9:00
今週も一週間よろしくお願いします！今週の全体会議は水曜15時からです。
有効
🔔 締切リマインダー BOT 毎月 25日 10:00
月末レポートの提出締切は今週金曜日です。未提出の方はお早めにお願いします。
一時停止中
📌
絵文字を直接入力するか、画像をアップロードします（アップロードした画像が優先されます。JPEG・PNG・WebP、5MBまで。F-37）。
「毎週」は初回日時の曜日、「毎月」は初回日時の日にちで繰り返します（該当日が存在しない月は月末に送信）。「1回のみ」は指定日時に1度だけ投稿し、以降は自動的に一時停止扱いになります。

特定のキーワードまたは絵文字を含む発言があったとき、自動でメッセージを投稿します（F-38）。チャンネルAIとは別物で、質問への理解や判断は行わず、単純な一致判定のみで動作します。

このチャンネルでのAIの有効/無効を切り替えます。AIを置かないチャンネル（雑談など）があってもかまいません。

# 開発相談 でAIを有効にする
無効にすると、このチャンネルでメンションしてもAIは応答しません。
対象チャンネル: # 開発相談（公開チャンネル・12名参加）

AIの名前・アイコン・口調を設定します（F-10）。

JPEG・PNG・WebP、5MBまで（F-37）。未設定の間は「AI」の2文字で表示されます。
この口調の指定は、次の「振る舞い定義」の内容と合わせてAIの応答生成に反映されます。

編集のたびに上書き保存されます。変更者・日時は監査ログ（S-08管理コンソール）に記録されます（過去バージョンの一覧・差分表示は対象外）。

回答の根拠とするフォルダ・文書の範囲を選択します（F-11）。一覧は管理コンソール（S-08）で登録された候補から選びます。

📄 運用ドキュメント（デプロイ手順書 ほか 12件）

📁 人事（9件）

ここで選んだ範囲であっても、質問者本人がGoogleドライブ上で閲覧権限を持たない文書は回答対象から除外されます（5.1節）。
厳格に制限
登録されたドキュメントや振る舞い定義・スキルの範囲外の質問には対応せず、「担当外のためお答えできません」のようにお断りする。
一般回答を許可
登録ドキュメントに根拠がない質問でも、AIの一般的な知識を使って回答する。社内ドキュメントを根拠にできる質問については、そちらを優先する。
⚠ 「一般回答を許可」を選ぶと、社内ドキュメントに基づかない回答が増えます。誤りを含みうる旨の注意喚起（F-30）はどちらの設定でも常時表示されます。

「依頼を受けたらこう進める」手順をスキルとして登録し、AIに割り当てます（F-12）。

AIがどのタイミングで応答するかを設定します（F-15）。

メンション時のみ応答
「@Kogack AI」と呼びかけられたときだけ応答します。会話に割り込みません。
投稿に自ら反応
メンションがなくても、チャンネル内の投稿内容に応じてAIが自発的に反応します。

依頼内容ごとに、AIが自動で対応してよい範囲を区分します（F-16）。
