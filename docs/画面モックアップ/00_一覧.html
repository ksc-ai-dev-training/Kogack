Kogack 画面モックアップ一覧

AIネイティブチャットシステム（Kogack）の画面モックアップ（静的HTML）です。各カードをクリックすると画面イメージを確認できます。
Ver 3.3 ／ 要件定義書 v1.18・基本設計書 v1.15（2026-08-26時点）に対応。S-01・S-03〜S-08 完成（S-02はS-03以降の共通サイドバーとして実装、単独モックアップなし）。
※ 各モックアップはそれ自体が製品画面の見た目を再現するため、このドキュメント一式共通のサイドナビは読み込んでいません。設定項目・入力項目の詳細は 要件定義書 および今後作成する基本設計書・詳細設計書を参照してください。

S-01 ログイン
全員（未認証）

Googleでログインボタンのみのシンプルな画面。許可ドメイン（kogasoftware.com）のみ利用可。許可ドメイン外エラー時の表示例も切替表示できる。
S-02 ワークスペース
member chadmin admin

参加中のチャンネル・DM一覧を表示するサイドバー（要件定義書4.1節）。単独の空状態画面としては起こしておらず、S-03以降の各画面に共通のサイドバーとして実装済み。個別モックアップファイルはなし。

S-03 チャンネル会話
チャンネル参加者

メッセージ一覧・投稿欄。AI発言のバッジと注意喚起、ドキュメント根拠・連携先システム参照結果・過去のやり取り参照をカードで区別して表示する。要約ボタン、送信予約ボタンあり。定期投稿・自動応答トリガー（BOT）はBOTバッジで区別。
S-04 スレッド表示
チャンネル参加者

特定の発言への返信をまとめて表示する右側パネル。元発言をハイライトし、AIとのやり取りをチャンネル本体の会話から分離する。
S-05 横断検索
member chadmin admin

メッセージ・ファイル・ドキュメント根拠を横断検索するタブ構成の結果画面。結果は参加チャンネル・DM、閲覧権限のある文書の範囲に限定される。in:/from:/with:/日付等の検索条件モディファイア（1.17版）に対応。
S-06 チャンネル設定
chadmin admin

「チャンネル管理者」タブ（公開／非公開の切り替えを含む）・「定期投稿」タブ・「自動応答トリガー」タブと、「AI設定の項目」（基本設定・キャラクタ〈アイコンは画像アップロード対応〉・振る舞い定義・参照ドキュメント範囲・スキル・反応モード・自動対応範囲の7タブ）に分けた構成。編集はそのチャンネルのchadminとadminのみ。
S-07 AI操作確認ダイアログ
依頼した本人

AIが社内システムへの登録・変更を実行する前に、実行内容を提示し同意を得るモーダル。座席予約の登録を例に表現（登録機能自体は次フェーズの実装対象）。
S-08 管理コンソール
admin

利用者管理（ロール変更・有効/無効化）・ドキュメント参照範囲（フォルダ追加/削除・同期）・AI利用状況とコスト（F-29）・監査ログ（ログイン記録、チャンネルAI設定の変更履歴）の4タブ構成。

補足モックアップ

要件定義書4.1節の画面一覧（S-01〜S-08）には独立した画面IDとして定義されていないが、F-02（チャンネル作成・参加）・F-05（DM）・F-35（送信予約）・F-37（プロフィール画像）の操作や、チャンネル管理者の可視化に必要なため補足として作成したモーダル。S-03サイドバーの「＋」、ヘッダーの参加人数、ヘッダーの「🕐 予約中」、またはヘッダーのユーザーメニューから遷移する。

補足 チャンネルに参加／作成
member chadmin admin

公開チャンネルの一覧から検索して参加する（即時参加）タブと、新しいチャンネルを公開／非公開を選んで作成するタブの2タブ構成のモーダル。作成者は自動的にchadminになる。非公開チャンネルは参加済みのものしか一覧に出ない。
補足 DMの相手を選ぶ
member chadmin admin

氏名・メールアドレスで利用者を検索し、チェックボックスで複数選択してDMを開始するモーダル。1人なら一対一、2人以上ならグループDM。既存のDMがある相手は区別して表示し、無効化されたアカウントは新規DMの対象外とする。
補足 メンバー一覧
member chadmin admin

チャンネルの参加人数（S-03ヘッダー）から開くメンバー一覧。chadminバッジで誰が管理者かを表示する。管理者の変更はS-06から行う。非公開チャンネルでは参加者なら誰でも「メンバーを追加」できる。
補足 予約中のメッセージ
member chadmin admin

ヘッダーの「🕐 予約中」から開く、自分が予約したメッセージの一覧。チャンネル・DMを横断して表示し、送信前ならいつでもキャンセルできる。指定時刻になると自動送信され、通常のメッセージと同じ扱いになる。
補足06 プロフィールを編集
member chadmin admin

ヘッダーのユーザーメニュー（自分のアバター）から開く、自分のアイコン画像・表示名の編集画面（1.16版で表示名の編集を追加）。同じアイコンの仕組みをチャンネルAI・定期投稿の送り主アイコンにも使う。
