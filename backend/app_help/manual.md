# Kogack 操作マニュアル（チャンネルAI参照用）

このファイルは docs/06_操作マニュアル.html の内容をプレーンテキストへ書き起こしたもので、
チャンネルAIが「このアプリ自体の使い方」を尋ねられたときに検索する専用の知識源です
（services/app_help_indexer.py が索引化、services/app_help_search.py が検索、
ai_agent.py の search_app_manual ツールから呼ばれる）。組織の業務文書（層2ドキュメントQ&A）
とは別物で、全チャンネル共通・管理者の登録操作なしに常時検索対象になります。

## 1. はじめに

Kogack（コガック）は、社内の会話にAIエージェントが常駐する社内チャットシステムです。
チャンネル・スレッド・ダイレクトメッセージ（DM）・横断検索・ファイル共有といった基本的な
チャット機能に加え、チャンネルごとに専用のAIをメンションして質問したり、社内ドキュメントを
参照した回答を得たりできます。

Kogackで何ができるか（主な機能8つ）: チャンネルでの会話、スレッド返信、ダイレクトメッセージ
（DM）、横断検索、デスクトップ通知、チャンネルAIへの質問、チャンネル設定、管理コンソール。
各機能の詳しい使い方は以降の章を参照。

ロール（権限）について: 利用者には member（一般）または admin（システム管理者）のいずれかの
ロールが割り当てられる。ロールの変更はシステム管理者が管理コンソールから行う。member は
参加しているチャンネル・DMのみ利用でき、自分がチャンネル管理者のチャンネルのみチャンネル
設定を編集できる。admin は同じ範囲に加え全チャンネルのチャンネル設定を編集でき、管理
コンソールも利用できる。この2ロールとは別に、チャンネルごとに「チャンネル管理者
（chadmin）」を複数人指定できる。チャンネル管理者はそのチャンネルのチャンネル設定
（AIのキャラクタ・振る舞い・参照ドキュメント範囲など）を編集できる。チャンネルを作成すると、
作成した本人が自動的にそのチャンネルの管理者になる。

動作環境: ブラウザは Google Chrome または Microsoft Edge の最新版を推奨する。ログインには
kogasoftware.com の社用Googleアカウントが必要（許可ドメイン外のアカウントではログイン
できない）。

## 2. ログインとログアウト

ログインする: ブラウザでKogackのURLを開くとログイン画面が表示される。「Googleでログイン」を
クリック→社用Googleアカウント（@kogasoftware.com）を選択→認証完了で自動的にKogackへ戻る。
初めてログインした場合、その時点で利用者として自動的に登録される（ロールは既定で「一般」）。
事前に管理者へ登録を依頼する必要はない。許可ドメインは kogasoftware.com のみで、個人の
Googleアカウントや他社ドメインのアカウントではログインできない。会社アカウントでも
ログインできない場合は、システム管理者にアカウントが「有効」になっているか確認する。
Googleの同意画面で「キャンセル」を選んだ場合もログインは完了しないため、もう一度
「Googleでログイン」を押し、表示された内容を「許可」する。

ログアウトする: サイドバー左下のユーザー情報の右にある「ログアウト」をクリックする。

## 3. 画面の基本構成

ログイン後はどの画面でも左側にサイドバーが常に表示される。サイドバーの構成要素は次のとおり。
チャンネル・DMの一覧行に✏️マークが付いている場合は、送信していない下書きが残っていることを
示す。
- 🕐: 予約中のメッセージ件数バッジ
- 🔔: デスクトップ通知の許可・受け取る範囲の設定
- チャンネル一覧: 参加中のチャンネルが名前順に並ぶ（表示件数の上限は無く、多い場合は
  サイドバーをスクロールする）。未読は太字＋件数バッジ、自分宛てメンションは赤い「@件数」
  バッジ、右の「＋」から参加・作成できる
- ダイレクトメッセージ一覧: 右の「＋」からDM相手を選んで開始できる
- チャンネル・DMの一覧を閉じる（折りたたむ・隠す）: チャンネルやDMが増えて一覧が長く
  なったときは、サイドバーの見出し「▼ チャンネル」「▼ ダイレクトメッセージ」をクリック
  するとその一覧を閉じられる（▼が▶に変わる）。閉じている間も、未読・メンションのあるものと
  今開いているものは表示されたままなので新着を見落とさない（既読にすると隠れる）。もう一度
  見出しをクリックすると全件の表示に戻る。開閉の状態はブラウザに保存され次回も引き継がれる
- 文字サイズを変更する（「文字を大きくしたい」「文字を小さくしたい」「画面の文字が
  小さくて見づらい」といった依頼はすべてこの機能で解決する。画面全体の表示倍率・
  フォントサイズの調整）: サイドバー下部（ユーザー情報の上）に「小／標準／大／特大」の
  4段階の切り替えボタンがあり、クリックすると画面全体の文字・表示の大きさがその場で
  変わる。文字を大きくしたい場合は「大」や「特大」を選ぶ。選んだ大きさは
  ブラウザに保存され、次回ログイン時・他のページに移動したときも引き継がれる（チャンネル
  ごとではなく、そのブラウザを使う自分の全画面に共通の設定）
- 📖 操作マニュアル: サイドバー下部（文字サイズの切り替えの下）にある。クリックすると
  サイドバーを表示したまま右側に操作マニュアルが開く（アプリ内でマニュアルを見る方法、
  マニュアルの場所）。右上の「新しいタブで開く」でブラウザの別タブに表示できる。チャンネルAIの
  回答の最後に付く「操作マニュアル」のリンクからも開ける
- 左下のユーザー情報: クリックするとプロフィール編集、右の「ログアウト」でログアウトする
- 🛠 管理コンソール: システム管理者にのみ表示されるリンク

## 4. チャンネル

チャンネルを探す・参加する・作成する: サイドバー「チャンネル」の右の「＋」をクリックすると
参加・作成モーダルが開く。「参加する」タブでチャンネル名を検索（空にすると未参加の公開
チャンネルが一覧表示される）→目的のチャンネルの「参加」をクリックすると即座に参加し会話
画面が開く。新しく作りたい場合は「作成する」タブでチャンネル名・説明（任意）・公開／非公開を
指定して作成する（作成者は自動的にそのチャンネルの管理者になる）。既存の参加者が
補足のメンバー一覧＝参加人数のボタンの「＋ メンバーを追加」から対象者を追加する方法は
公開チャンネルでも使える（自己参加と並ぶもう1つの参加経路）。非公開チャンネル
（🔒アイコン）は一覧・検索に表示されず自己参加ができないため、この「＋ メンバーを
追加」による方法しか無い。参加していない非公開チャンネルは存在自体がURLを直接入力
しても分からない。

チャンネル会話画面の見方: ヘッダー・メッセージ一覧・投稿欄（Composer）の3エリアで構成
される。ヘッダーにはチャンネル名・説明文（クリックでチャンネル情報を確認）、検索欄
（クリックでこのチャンネルに絞り込んだ横断検索へ）、👥所属メンバー：N人（参加者一覧、
非公開チャンネルへのメンバー追加もここから）、📝要約（直近のやり取りをAIに要約してもらう）、
🔔（このチャンネルの通知設定の上書き）、⚙チャンネル設定（チャンネル管理者・システム
管理者のみ表示）がある。

チャンネル情報（説明文・公開/非公開・作成者・作成日時）を確認する方法: ヘッダーの
チャンネル名をクリックすると開くモーダルの「チャンネル情報」タブで、そのチャンネルの
説明文・公開／非公開の別・作成者（氏名）・作成日時を確認できる。この確認はチャンネル
管理者（chadmin）やシステム管理者に限らず、そのチャンネルの参加者なら誰でもできる
（特別な権限は不要）。同じモーダルには退出するボタンもある。

チャンネルから退出する・メンバーを確認する: ヘッダーの「👥所属メンバー」から開くモーダルの
「メンバー」タブでは各参加者の行から強制退出させることもできる（チャンネル管理者・
システム管理者のみ）。「チャンネル情報」タブの退出ボタンとあわせて、そのチャンネルの
最後の1人のチャンネル管理者は退出・解除できない（管理者不在の防止）。

## 5. メッセージを送る

基本の送信操作: 投稿欄にメッセージを入力し、Ctrl+Enter（Macは⌘+Enter）または右下の
「送信」ボタンで送信する。Enterキー単体は改行になる（Slackと同じ操作感）。1件あたり
4,000文字まで入力できる。

書式を付ける（書式の表現方法）: メッセージには太字・斜体・下線・取り消し線・コード（1行）・
コードブロック・リンク・箇条書き・引用の書式を付けられる。投稿欄の上に並ぶ書式ツールバーの
ボタン、キーボードショートカット、記法の直接入力のどれでも同じ書式になる。コード（1行）と
コードブロックのボタンは隣り合わせに並んでいる。
- 太字: Bボタン、ショートカットCtrl+B、記法 `**太字**`
- 斜体: Iボタン、ショートカットCtrl+I、記法 `_斜体_`
- 下線: Uボタン、ショートカットCtrl+U、記法 `++下線++`
- 取り消し線: Sボタン、ショートカットCtrl+Shift+X、記法 `~~取り消し線~~`
- コード（1行、</>ボタン）: バッククォートで囲む。等幅フォント・背景色付きで1行のコードとして
  表示される。複数行を選択している場合は使えない（隣のコードブロックボタンを使う）。投稿欄で
  入力中にEnterで改行してもコードブロックには変わらず、改行の前後がそれぞれ独立した1行のコード
  として続けて入力できる
- コードブロック（四角にコードのマークが入ったボタン）: 3連バッククォートで囲む。選択範囲
  （無ければ現在行）を枠で囲まれたコードブロックにする。選択範囲が無い状態で押すと空の
  コードブロックを作れる。既存のコードブロックの中で押すと解除される
- リンク: `[表示文字](URL)`。🔗ボタンを押すとテキストとURLを入力するポップアップが開く
- 箇条書き: 行頭に `- `。≡ボタンでも付けられる。箇条書きの行でEnterを押すと次の行にも自動で付く
- 引用（Slackと同じ引用タグ）: 行頭に `> `。左に縦線が入ったブロックとして表示される。
  引用の行でEnterを押すと次の行にも自動で付く。ツールバーの縦線アイコンのボタンからも
  選択範囲を引用にできる（既に引用済みなら解除される）
Macではショートカットの Ctrl を ⌘ に読み替える。

書式の付け方は3通りある:
1. 文字列を選択してからボタン（またはショートカット）を押す → 選択した範囲にその書式が付く。
   同じボタンをもう一度押すと解除される
2. 何も選択せずにボタン（またはショートカット）を押す → ボタンが色付き（オン）になり、それ以降に
   入力する文字にその書式が付く。もう一度押すとオフに戻り、以降は普通の文字になる
3. 記法を直接入力する → 例えば `**太字**` と入力すると、閉じ側の記号を打った時点で記号が消えて
   投稿欄の中でもその場で太字に変わる。行頭に `- ` と打つと箇条書きに、`> ` と打つと引用に
   変わる。コードブロックは3連バッククォートで囲んで入力しても送信後にコードブロックとして
   表示される

書式の組み合わせ: 太字・斜体・下線・取り消し線は重ねて使える（例: 太字ボタンと斜体ボタンを両方
オンにすると太字の斜体になる。記法では `**_太字の斜体_**`）。コード（1行）だけは他の書式と
組み合わせられず、コードがオンの間は太字等のボタンが、太字等がオンの間はコードのボタンが
押せなくなる。

箇条書き・引用を終える: 何も入力していない（空の）箇条書き・引用の行でもう一度Enterを押すと、
箇条書き・引用が終わって普通の行に戻る。

対応していない書式: Kogackで使える書式は上記のものだけ。見出し（行頭の `#`）、番号付きリスト
（`1. `）、表、文字色・文字サイズの変更、箇条書きの入れ子（字下げ）には対応しておらず、入力した
記号はそのまま文字として表示される。

書式が使える場所: チャンネル・DM・スレッドの投稿欄のほか、発言の編集画面、定期投稿・自動応答
トリガーの本文欄でも書式ツールバーが使える。ただし編集画面・本文欄では、書式ボタンを押すと
`**` などの記号が文字のまま入り、送信（保存）後に書式として表示される（入力中にその場で太字等に
変わるのと、キーボードショートカットは投稿欄だけの機能）。チャンネルAIの回答も同じ書式で
表示される。

URLを含む文章を送るとURLは自動的にリンク化される。文章を選択した状態でURLを貼り付けると、
選択していた文字列を表示名にしたリンクに変換される。

メンションする: 投稿欄に「@」を入力すると、メンションできる相手の候補が一覧表示される。
↑↓キーとEnter（またはクリック）で選ぶと本文に挿入される。
- 特定の利用者（例: 山田 太郎）: その人だけに通知が届く
- channel: チャンネルの参加者全員に通知が届く（Slackの@channel相当）
- here: 送信した時点で実際にKogackを見ていた（直近30秒以内に操作していた）参加者だけに
  通知が届く（Slackの@here相当）
- チャンネルAI（例: Kogack AI）: そのチャンネルのAIに呼びかける。チャンネルAIが有効な
  チャンネルのみ候補に出る

コードの中の「@」はメンションにならない: コード（1行、バッククォートで囲む）・コードブロック
（3連バッククォートで囲む）の中に書いた「@名前」「@channel」「@here」「@Kogack AI」などは
メンションとして扱われない。通知は届かず、チャンネルAIも反応せず、書いた文字はそのままコード
として表示される。コードの中で「@」を打ってもメンション候補は開かない。メンションの書き方
そのものを説明したいとき（例:「AIを呼ぶときは `@Kogack AI 質問` と書きます」）に使える。

絵文字を送る: 投稿欄下のスタンプアイコンをクリックすると絵文字の一覧（ピッカー）が開く。
選ぶとカーソル位置に挿入される。メッセージの本文が絵文字だけの場合は通常より大きく
表示される（ジャンボ絵文字）。

- カスタム絵文字を作成する: 絵文字ピッカーの末尾にある「＋」をクリックすると、独自の
  絵文字を登録できる。名前（半角英数字・_・-、2〜24文字）と画像（JPEG・PNG・WebP、
  5MBまで）を指定して「追加する」を押すと登録される。利用者なら誰でも登録できる
  （管理者権限は不要）。登録した絵文字は以後すべての利用者のピッカーに表示され、
  メッセージ本文・リアクション（6.3節参照）の両方で他の絵文字と同じように使える。
- カスタム絵文字を削除する（スタンプの削除方法）: 登録した本人またはシステム管理者だけが
  削除できる。絵文字ピッカーでその絵文字にカーソルを合わせると右上に「×」が表示される
  ので、クリックして確認ダイアログで「削除する」を押す（削除できない絵文字には「×」は
  出ない）。削除すると全員のピッカーから消え、既にその絵文字を使ったリアクション・発言では
  画像の代わりに:名前:という文字列で表示される。

ファイルを添付する: 投稿欄のクリップアイコンからファイルを選ぶと、送信前にアップロードされ
チップとして表示される（✕で取り消し可）。1ファイルあたり20MBまで、形式の制限はない。
送信された添付ファイルは、画像・PDF・プレーンテキスト（txt/md/csv/json/log）であれば
クリックしてその場でプレビューでき、それ以外の形式はダウンロードのみになる。

下書きは自動保存される: 送信せずに別のチャンネル・DM・スレッドへ移動しても、入力中の内容は
ブラウザ内に自動保存される。戻ってくると復元され、下書きが残っているチャンネル・DM・
スレッドはサイドバーや会話一覧に✏️マークで示される。

アンケート（投票）を作成する: チャンネル・DMの投稿欄の左下に並ぶアイコン（クリップ・
スタンプ・@）の右隣にある、棒グラフのアイコンの「アンケートを作成」ボタンを押すと
「アンケートを作成」画面が開く。
1. 「質問」欄に質問文を入力する（例: 次回の懇親会はいつがいいですか？）
2. 「選択肢」欄に選択肢を入力する。選択肢は2〜10件で、「＋ 選択肢を追加」で行を増やし、
   各行の右の✕で減らせる（2件より少なくはできない）。空欄の行は無視される
3. 「作成する」を押すと、会話にアンケートが投稿される（「キャンセル」で作成をやめる）
- そのチャンネル・DMの参加者なら誰でも作成できる（管理者権限は不要）。自分専用DMでも作れる
- スレッドの返信欄にはアンケートのボタンが無く、スレッド内には作成できない
- 作成したアンケートの質問・選択肢は後から編集できない（直したい場合は削除して作り直す）

アンケートに投票する: 会話に表示されたアンケート（📊と質問文のカード）の選択肢をクリック
するだけで投票できる。
- 1人1票の単一選択で、複数の選択肢を同時に選ぶことはできない
- 締め切り前であれば、別の選択肢をクリックすると投票し直せる（投票自体の取り消しはできない）
- 自分が投票した選択肢には✓が付き、枠が色付きになる
- 各選択肢の票数と割合（%）、合計票数は参加者全員に表示される。選択肢にマウスを重ねると、
  その選択肢に投票した人の名前が表示される（匿名投票の機能は無い）

アンケートを締め切る: アンケートの右下にある「アンケートを締め切る」を押す。締め切れるのは
アンケートを作成した本人とシステム管理者だけで、それ以外の人には表示されない。締め切ると
「締め切り済み」と表示され、以後は誰も投票できなくなる（結果はそのまま会話に残る）。
締め切りを取り消して再開する機能、日時を指定して自動で締め切る機能は無い。アンケート
そのものが不要になった場合は、通常の発言と同じくホバーアクション・右クリックメニューの
「削除」で消せる（投稿者本人またはシステム管理者）。

チャンネルAIにアンケートの結果を尋ねる: チャンネルAIをメンションして「このアンケートの
結果は？」のように聞くと、会話中のアンケートの選択肢ごとの票数・投票した人・締め切り
状態をもとに答える。チャンネルの要約（11.2節）にもアンケートの結果が反映される。

## 6. メッセージを操作する

ホバーで出てくるアクション: メッセージにマウスを重ねると右上にアクションバーが表示される。
👍❤️😂🎉👀（クイックリアクション、クリックした絵文字でリアクションを付ける。もう一度
押すと取り消す）、😊（絵文字を選んでリアクション、ピッカーから任意の絵文字を選ぶ）、
返信（そのメッセージにスレッドで返信する）、編集（自分が投稿したメッセージの本文を
書き換える）、削除（自分の投稿、またはシステム管理者ならどの投稿でも削除できる）。
AI発言には加えて🔍（送信内容、そのチャンネルの管理者・システム管理者にのみ表示。
AIへ実際に送信した内容を確認できる）が出る。

右クリックメニュー（メッセージのコピー方法・テキストのコピー方法・リンクのコピー方法）:
メッセージを右クリックすると、「返信する」「編集する」「コピーする」「リンクをコピー」
「削除する」の5項目をメニュー形式でも呼び出せる（項目の表示条件はホバー時アクションと
同じで、編集・削除は自分の投稿のみ、削除はシステム管理者なら他人の投稿にも表示される。
「コピーする」「リンクをコピー」は誰の投稿でも常に表示される）。「コピーする」を選ぶと
本文をクリップボードにコピーする。「引用返信」「ピン留め」のような、これら5項目以外の
操作はKogackの右クリックメニューには無い。

発言へのリンク（メッセージのリンクを貼る方法・過去のスレッドを参照させる方法）:
右クリックメニューの「リンクをコピー」で、その発言へのリンク（URL）をコピーできる
（スレッド内の返信にも使える）。チャンネルやDMに貼ったリンクをクリックすると、リンク先の
発言まで移動して一時的にハイライト表示される。「@Kogack AI この話の結論は？ （リンク）」
のようにAIへのメンションと一緒に貼ると、AIがリンク先の発言とその前後の会話（スレッドの
返信を含む）を読んで回答する。1回に読み取るリンクは3件まで。AIが読み取るのは同じチャンネル
内または公開チャンネルの発言のみで、非公開チャンネル・DMの発言のリンクは内容を読み取らない
（AIの回答はチャンネル参加者全員に見えるため）。

リアクションを付ける: 付いているリアクションのピル（例: 👍 2）にカーソルを合わせると誰が
付けたかがポップアップで表示される。ピルをクリックすると自分のリアクションを取り消せる
（他人のリアクションは消えない）。同じメッセージに誰でも何個でも異なる絵文字でリアクション
できる。「絵文字を選んでリアクション」のピッカー末尾の「＋」からもカスタム絵文字を登録でき、
そのままリアクションとして使える。

編集する・削除する: 編集は自分が投稿したメッセージのみ行える（管理者でも他人の発言は
編集できない）。「編集」を押すと本文がその場でテキストエリアに切り替わり、Ctrl+Enterで
保存・Escapeで取消する。保存すると投稿時刻の隣に「（編集済み）」と表示される。編集画面
でも書式ボタン・絵文字・添付ファイルの追加/削除が使える（ただし新たなメンションの追加は
できない）。削除は投稿者本人、またはシステム管理者が行える。削除には確認が入り、取り消せ
ない。なお、チャンネルへの参加・退出を知らせるシステム通知は、記録としての信頼性を保つため
返信・削除の対象外。

過去のメッセージをさかのぼる: 会話画面は直近のメッセージのみを表示する。一覧の一番上に
「▲ 古いメッセージを読み込む」ボタンが出ている場合はクリックするとさらに古いメッセージを
読み込める。横断検索の結果からジャンプした場合は、その発言までさかのぼって薄いオレンジ色で
一時的にハイライトされる。

## 7. スレッドで返信する

特定の発言に対して会話を続けたい場合はスレッドを使う。スレッド内のやり取りは本体の会話
タイムラインには流れず、元の発言の下に「N件の返信」として表示される。返信したい発言を
ホバーし「返信」をクリックするか、既に返信がある発言の「N件の返信」をクリックすると、
画面右側にスレッドパネルが開く。スレッドパネル下部の投稿欄から返信を送信する（通常の
投稿欄と同じく書式・メンション・絵文字・ファイル添付が使える）。スレッドパネルの横幅は
左端をドラッグして調整でき、次回開いたときも幅を引き継ぐ。自分の発言に返信が付いたとき・
スレッド内で自分がメンションされたとき・自分が一度でも返信したスレッドに新しい返信が
来たときは、そのチャンネルの一般的な通知設定に関わらずデスクトップ通知が届く。

## 8. ダイレクトメッセージ（DM）

DMを始める: サイドバー「ダイレクトメッセージ」の右の「＋」をクリックするとDM相手を選ぶ
モーダルが開く。氏名またはメールアドレスで検索し、相手をチェックして「DMを開始する」を
クリックする。1人選べば1対1のDM、2人以上選べばグループDMになる。既に同じ組み合わせの
DMがあれば新規作成せずそのDMが開く（「DM済み」の表示で確認できる）。一覧の「自分」を
選ぶと、メモ・下書き・To-doの保管に使える自分専用のDMを開始できる。無効化されたアカウント
は「無効化済み」と表示され選択できない。

DM画面の見方: 構成はチャンネル会話とほぼ同じ。ヘッダーには相手（またはグループ）の氏名、
検索欄（with:で絞り込んだ横断検索へ移動）、このDMだけの通知設定ボタンがある。日付が
変わった区切りと、開いた時点で未読だったメッセージの手前に「ここから未読メッセージ」の
区切り線が表示される。チャンネルAIはチャンネル専用の機能のため、DMでは利用できない
（メンション候補にも出ない）。

自分専用DM（メモ）: サイドバーには📝アイコン付きで「自分（メモ）」として表示される。他の
誰にも見えない、個人のメモ・下書き・To-do・リンクの保管用途に使える。投稿・検索・添付
ファイルなど通常のDMと同じ機能がすべて使える。

## 9. 検索する

チャンネル会話・DM画面ヘッダーの検索欄をクリックするか、横断検索画面（/search）を開くと、
自分が参加しているすべてのチャンネル・DMのメッセージと添付ファイルを横断的に検索できる。
フリーワードに加え、次のモディファイア（条件指定子）を組み合わせられる。in:・from:・with:
は入力中に候補ポップオーバーが開き選んで確定する。before:・after:・on:・during:は
カレンダー入力欄から日付を選べる。
- in:チャンネル名 — 指定したチャンネルの発言に絞り込む
- from:氏名 — 指定した投稿者の発言に絞り込む
- with:氏名 — 指定した相手とのDMに絞り込む
- before:2026-09-09 / after:2026-09-09 — 指定日より前／後に絞り込む
- on:2026-09-09 — 指定日当日に絞り込む
- during:2026-09 — 指定月に絞り込む
- "完全一致のフレーズ" — ダブルクォートで囲むと完全一致で検索する

検索結果は「すべて／メッセージ／ファイル」タブで切り替えられる（クリックしても再検索は
しない）。1タブに20件を超える結果がある場合は「もっと見る」で追加取得できる。「ドキュメント
根拠」タブは社内ドキュメントの内容そのものを横断検索する機能で、現時点では未実装のため
常に無効表示（チャンネルAIに直接質問すれば、AIがドキュメントを検索して回答することは
できる）。

## 10. 通知

デスクトップ通知を設定する: サイドバー左上の🔔をクリックすると設定ポップオーバーが開く。
初回は「通知を有効にする」を押しブラウザの許可ダイアログで「許可」する。受け取る範囲は
「すべての新着」「メンション・DMのみ」「オフ」の3択。通知にはブラウザのタブを開いている
間だけ届く方式と、ブラウザ・タブを閉じていても届く方式（Web Push）の2種類があり、両方の
許可が同時に行われる。ブラウザの通知許可自体はアプリ側から取り消せないため、「今は通知を
受け取らない」と決めた場合はブラウザの許可を取り消すのではなく「オフ」を選ぶ。

チャンネル・DMごとに通知を変える: チャンネル会話・DM画面ヘッダーの🔔からも、そのチャンネル・
DM限定で通知設定を上書きできる（既定＝全体設定に従う）。「オフ」を選ぶと、そのチャンネル・
DMはサイドバーの未読バッジも表示されなくなる（ミュート）。

未読・メンションの表示: グレーの件数バッジ＝未読メッセージがある。赤い「@件数」バッジ＝
自分宛てのメンション（@氏名・@channel・@here）を含む未読がある（件数の代わりに優先して
表示される）。ブラウザのタブタイトル＝未読の合計件数を「(N) 」の形で先頭に表示する。

## 11. チャンネルAIに質問する

メンションして質問する: チャンネルAIが有効なチャンネルでは、本文中に「@Kogack AI」
（チャンネルごとに名前を変更できる）のようにメンションして投稿すると、AIが同じチャンネルへ
返信する。生成中は「生成中…」の点滅表示になり、長くかかりすぎる場合は誰でも「■ 中断」
できる。チャンネルの設定によっては、メンションしなくても人間の発言に自発的に応答する
「反応モード」になっている場合もある。

やり取りを要約してもらう（メッセージを要約する方法・会話を要約する方法・
スレッドを要約する方法・要約機能の使い方）: チャンネルヘッダーの「📝 要約」
ボタンを押すと、直近のやり取り
（最大100件）をAIが要約してチャンネルへ投稿する。▾から「今日／今週／今月／直近7日間／
直近30日間」または任意の期間を指定して要約することもできる。チャットで「@Kogack AI
○○を要約して」のように依頼しても同じ動作をする。要約結果には「📝 要約」バッジが付き、
通常のAI応答と区別できる。スレッドパネルの「📝 要約」ボタンは、そのスレッド全体を要約
する。メッセージを右クリックしたメニュー・ホバー時のアクションメニューには要約機能は
無い（要約は個々のメッセージ単位ではなく、チャンネル・スレッド単位でのみ実行できる）。

社内ドキュメントを参照した回答: チャンネル設定の「参照ドキュメント範囲」でドキュメントが
割り当てられているチャンネルでは、AIが必要に応じてそのドキュメントを検索してから回答
する。回答の根拠にした文書は「📄 参照: ファイル名」として表示される。AIの回答には誤りが
含まれる場合があるため、実際に参照元を確認したいときは、対応形式（画像・PDF・プレーン
テキスト）のファイル名をクリックするとアプリ上でそのまま内容を確認できる（そのチャンネル
の参加者であれば誰でも見られる）。

AIの回答について: AIの回答には誤りが含まれる場合がある。すべてのAI発言の下に注意書きが
常に表示される。重要な判断が必要な内容は、必ず元の資料や関係者に確認すること。
Kogackの機能・使い方についてAIに質問すると、回答の最後に「詳しくは操作マニュアルをご確認
ください。」と表示され、「操作マニュアル」の部分のリンクをクリックすると、回答内容に関係する
章から操作マニュアルが開く。

AIへの実際の送信内容を確認する方法（チャンネル管理者・システム管理者向け）: AIの発言に
マウスを重ねると出るホバーアクションの「🔍 送信内容」ボタン（そのチャンネルの管理者・
システム管理者にのみ表示される。一般の参加者には表示されない）を押すと、その発言を
生成する際に実際にOpenAI APIへ送信したシステムプロンプト・会話履歴・ツール呼び出しの
内容がそのまま確認できる。使用したAIモデル名・入出力トークン数・概算コストもあわせて
表示される。

## 12. チャンネル設定（チャンネル管理者向け）

チャンネル会話画面ヘッダーの「⚙ チャンネル設定」は、そのチャンネルの管理者、または
システム管理者にのみ表示される。左側のナビゲーションで各タブを切り替える。設定内容を
変更して保存せずに他の画面へ移動しようとすると確認メッセージが表示される。

チャンネル管理者タブ: チャンネル名・説明文の編集、公開／非公開の切り替え、チャンネル
管理者の追加・解除、チャンネルの削除を行う。チャンネルの削除は取り消せない。会話ログ・
スレッド・送信予約・AI設定を含め、すべてのデータが完全に削除される。削除するには確認欄に
チャンネル名を正確に入力する必要がある。

AI設定タブ群: 「AI設定の項目」グループにある7つのタブでそのチャンネルのAIの振る舞いを
設定する。
- 基本設定 — このチャンネルでAIを有効／無効にする。使用するAIモデルも選べる（速度重視
  ならgpt-4.1-nano・gpt-4.1-mini、コスト重視ならgpt-5-nano、応答品質重視なら既定の
  gpt-5-mini）
- キャラクタ — AIの名前・アイコン画像・口調を設定する
- 振る舞い定義 — AIの応答方針を自由記述で指定する。変更者・日時は監査ログに記録される
- 参照ドキュメント範囲 — 管理コンソールに登録済みのファイルから、このチャンネルのAIが
  参照してよい範囲を選ぶ。参照範囲外の質問に一般知識で答えてよいかも選べる
- スキル — AIが対応できる業務の一覧と、どのスキルにも当てはまらない依頼の引き継ぎ先
  （参加者から選ぶ）を設定する
- 反応モード — 「メンション時のみ応答」または「投稿に自ら反応」を選ぶ
- 自動対応範囲 — 依頼内容のカテゴリごとに「自動対応可／確認のうえ対応／人が対応」を
  設定する

定期投稿・自動応答トリガー: 「その他の設定」グループの「定期投稿」タブでは、
決まった時刻に自動投稿するメッセージ（毎日／毎週／毎月／月〜金／月末など）を登録できる。
「自動応答トリガー」タブでは、特定のキーワード・絵文字を含む発言に自動でBOTが返信する
ルールを登録できる。いずれも本文に「@（チャンネルAIの名前）」を含めれば、投稿後にAIが
応答することもできる。

メッセージを予約する（送信予約）: 投稿欄の🕐（送信日時を指定）ボタンから、通常のメッセージを
指定した日時に1回だけ送信予約できる。「メッセージの予約」「予約投稿」も同じ機能を指す。
**チャンネル管理者専用の機能ではなく、そのチャンネル・DMの参加者であれば誰でも使える**
（この段落が「チャンネル設定（チャンネル管理者向け）」の章にあるのは、定期投稿・自動応答
トリガー（いずれもチャンネル管理者専用）と同じ投稿欄機能としてまとめて記載しているためで、
送信予約自体の利用に管理者権限は不要）。操作手順は次のとおり。
- 投稿欄にメッセージを入力する（この時点ではまだ送信しない）
- 送信ボタンの隣にある🕐（送信日時を指定）アイコンをクリックする
- 開いたポップオーバーで送信したい日付・時刻を選ぶ
- ポップオーバー内の「予約する」ボタンを押して確定する（通常の送信ボタンやCtrl+Enterでは予約されない、必ずポップオーバー内の「予約する」ボタンを押すこと）

予約が完了すると、指定した日時に自動的に投稿される。送信されるまでは自分だけが内容を確認・
取り消しできる。予約中のメッセージはサイドバー上部の🕐バッジ（予約確認ボタン）をクリックすると
一覧が開き、確認・取り消しができる。

## 13. 管理コンソール（システム管理者向け）

サイドバー下部の「🛠 管理コンソール」はシステム管理者にのみ表示される。4つのタブで
構成される。

利用者管理: 登録済みの利用者の一覧、ロール（member／admin）の変更、アカウントの有効／
無効の切り替えを行う。新規作成・削除はできない（Google認証での初回アクセス時に自動登録
されるため）。退職者などアカウントを無効化すると、そのGoogleアカウントではログイン
できなくなる（過去の発言は削除されず残る）。管理者は自分自身をロール変更・無効化
できない（管理者不在の防止）。

ドキュメント参照範囲: チャンネルAIが回答の根拠として参照できる社内ドキュメントを登録
する。ファイルをドラッグ＆ドロップ、またはクリックして選択（フォルダごとの一括登録も
可能）すると、自動でテキストが抽出・索引化され、AIが質問に応じて検索できるようになる。
登録時に「限定公開にする」を選ぶと、指定した利用者だけが閲覧できるドキュメントとして
扱われる（限定公開のドキュメントは、参加者全員が閲覧権限を持つ非公開チャンネルにのみ
割り当てられる）。各チャンネルは登録済みの候補の中から使う範囲をチャンネル設定側で
選ぶ。画像・PDF・プレーンテキスト（txt/md/csv/json/log）のファイルは、一覧の
「プレビュー」ボタンからアプリ上でそのまま内容を確認できる（それ以外の形式は
プレビュー非対応で、ボタン自体が表示されない）。この機能はシステム管理者のみ利用できる。

AI利用状況・コスト: 月ごとのAI呼び出し件数・トークン数・概算コストを、チャンネル別・
利用者別に集計して確認できる。質問文・回答文そのものは記録されない。チャンネルごとに
月次の上限額と通知しきい値を設定することもできる。表示される金額は目安であり、正確な
請求額は別途確認する。

監査ログ: ログインと、チャンネルAI設定の変更（振る舞い定義・参照ドキュメント範囲など）
を、いつ・誰が・どの項目を変更したかという単位で記録する。変更内容そのもの（差分・
本文）は保持しない。種別・実行者・対象チャンネル・期間で絞り込んで確認できる。

## 14. よくある質問・困ったとき

- ログインできない → 社用Googleアカウント（@kogasoftware.com）でログインしているか
  確認する。それでも入れない場合はシステム管理者にアカウントが「有効」か確認を依頼する。
- 初めて使うが利用登録は必要か → 不要。社用Googleアカウントで初めてログインした時点で
  「一般」ロールとして自動的に登録される。
- サイドバーに「🛠 管理コンソール」が出ない → ロールが「一般（member）」の場合は
  表示されない。管理コンソールを使う必要がある場合はシステム管理者にロール変更を依頼する。
- 他の人の発言に「編集」ボタンが出ない → 編集は投稿者本人のみ行える（管理者でも他人の
  発言は編集できない）。内容の修正は本人に依頼するか、削除（投稿者本人・管理者が可能）を
  依頼する。
- チャンネルの「⚙ チャンネル設定」が見えない → そのチャンネルの管理者（chadmin）または
  システム管理者にのみ表示される。既存の管理者に自分を追加してもらうか、システム管理者に
  依頼する。
- 公開チャンネルに参加したい → 2通りの方法がある。(1) サイドバー「チャンネル」の右の
  「＋」→「参加する」タブでチャンネル名を検索（空欄なら未参加の公開チャンネルが一覧
  表示される）→「参加」をクリックすれば自分だけの操作ですぐに参加できる（既存の参加者
  への依頼や承認は不要）。(2) 既存の参加者に「👥 所属メンバー」のメンバー一覧から
  「＋ メンバーを追加」で追加してもらうこともできる（非公開チャンネルと同じ方法）。
- 非公開チャンネルに参加したい → 非公開チャンネルは一覧・検索に出てこないため、自分で
  参加することはできず、既存の参加者に「👥 所属メンバー」のメンバー一覧から追加して
  もらう必要がある。
- デスクトップ通知が届かない → ブラウザの通知許可がされているか、通知設定が「オフ」に
  なっていないか（全体・チャンネル/DM個別の両方）を確認する。ブラウザ側で通知が
  ブロックされている場合はブラウザのサイト設定から許可する。
- 「@Kogack AI」とメンションしても反応しない → そのチャンネルでチャンネルAIが無効に
  なっている可能性がある。チャンネル管理者に確認を依頼する。
- 検索してもヒットしない → 検索対象は自分が参加しているチャンネル・DMの発言・添付
  ファイルに限られる。モディファイアの日付形式はYYYY-MM-DD（during:のみYYYY-MM）。
- 参加しているチャンネルが多くてサイドバーが長い → サイドバーの見出し「▼ チャンネル」
  「▼ ダイレクトメッセージ」をクリックすると一覧を閉じられる。閉じている間も未読・メンション
  のあるものと今開いているものは表示される。
- 操作マニュアルをアプリの中で見たい → サイドバー下部の「📖 操作マニュアル」をクリックする。
- アンケートの「アンケートを締め切る」が出ない → 締め切れるのはアンケートを作成した本人と
  システム管理者だけ。作成者に締め切りを依頼する。
- スレッドでアンケートを作りたい → スレッドの返信欄にはアンケートのボタンが無く、作成できる
  のはチャンネル・DMの投稿欄からだけ。
- アンケートで投票を間違えた → 締め切り前なら正しい選択肢をクリックし直せば投票が
  切り替わる。
- 添付ファイルがプレビューできない → プレビューは画像・PDF・プレーンテキストのみ対応。
  それ以外の形式（Word・Excel等）はダウンロードしてから確認する。
